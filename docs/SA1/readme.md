# Situación de Aprendizaje Inclusiva: "Hablamos con las Manos, Aprendemos con el Corazón"

Este repositorio contiene los archivos fuente del sitio web completo dedicado a la estructuración de la Situación de Aprendizaje (SA) inclusiva para el Primer Ciclo de Educación Infantil (grupo de 2 a 3 años), centrada en la **Lengua de Signos Española (LSE)**.

El diseño y contenido se ajustan de manera estricta y rigurosa al marco regulatorio del **R.D. 95/2022**, la **Orden ECD/853/2022 de la Comunidad Autónoma de Aragón**, y toma como premisa fundamental la **Ley 27/2007** de reconocimiento de las lenguas de signos españolas.

## 📁 Estructura del Proyecto

El sitio web está desarrollado utilizando estándares modernos y limpios de desarrollo web estático (HTML5 semántico, CSS3 adaptable y JavaScript nativo), ideal para un despliegue optimizado, seguro y sin costes mediante **GitHub Pages**.

```text
├── index.html          # Página de Inicio: Justificación, Contexto de aula y Objetivos
├── planificacion.html  # Saberes básicos, Metodología e inclusión DUA
├── sesiones.html       # Guía secuenciada al completo de las 15 sesiones de intervención
├── evaluacion.html     # Organización de espacios regulados, recursos e instrumentos de evaluación
├── anexos.html         # Índice de anexos normalizados de aula y advertencias legales primarias
├── style.css           # Arquitectura de estilos CSS responsive con criterios de accesibilidad (WCAG 2.1)
├── script.js           # Lógica interactiva y adaptabilidad del menú móvil
